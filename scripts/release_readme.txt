TTC_Siren —— 九宫幻卡 AI 求解服务

使用方法
1. 把整个文件夹解压到任意位置（路径可以有中文）。
2. 双击 TTC_Siren.exe，出现控制台窗口即为运行中。
   第一次启动会先解压自身，可能需要几秒。启动信息里显示“C# 求解引擎: 已启动”即正常。
3. 插件（幻卡助手 / 幻卡锦标赛）的服务地址填 http://127.0.0.1:5000 ，不需要密钥。
4. 关闭控制台窗口即停止服务，求解引擎会一起关闭。

注意
- engine 文件夹必须和 TTC_Siren.exe 放在一起（里面是 C# 求解引擎）。
- 不需要安装 Python 或 .NET。
- 只监听本机 127.0.0.1，不会对外开放端口。
- 如果 5000 端口被其他程序占用，服务会启动失败；关闭占用端口的程序后重试。
- 杀毒软件可能误报 PyInstaller 打包的 exe，请添加信任。
