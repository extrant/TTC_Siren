# Mascot assets (Seren / 瑟琳)

Put the GPT-generated originals in `raw/`, named exactly as listed in `docs/design/MASCOT.md` section 2
(`seren_ref_sheet.png`, `seren_e01_neutral.png` ... `seren_e08_disappointed.png`, optional `seren_p01_shuffle.png`, ...).

Requirements: PNG, transparent background (the reference sheet may be on white), 1024x1536 portrait for expressions and
full-body poses, identical framing across expressions. Originals are never edited; the Phase 8B build converts them.
